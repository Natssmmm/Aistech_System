FIX ADMIN TEXT, NUMBER, AND ICON VISIBILITY IN DARK MODE AND LIGHT MODE

ROOT CAUSE:
The visibility issues were caused by:
1. Bootstrap text color utility classes (text-primary, text-success, text-danger, text-warning, text-info) using fixed colors that did not adapt to the dark/light theme.
2. Some alert and badge classes requiring theme-specific adjustments for optimal contrast on colored backgrounds.
3. Fixed text-white icons on gradient backgrounds (stat-icons) that, while having sufficient contrast, were not theme-adaptive.
4. Toast notifications using fixed white text that did not have sufficient contrast on certain brand-colored backgrounds (error and warning toasts).

FILES MODIFIED:
- C:\xampp\htdocs\kiosk\assets\css\darkmode.css
- C:\xampp\htdocs\kiosk\assets\js\app.js

FIXES APPLIED:
1. Added theme-aware overrides for Bootstrap text color utilities in darkmode.css:
   .text-primary   { color: var(--primary) !important; }
   .text-success   { color: var(--success) !important; }
   .text-danger    { color: var(--danger) !important; }
   .text-warning   { color: var(--warning) !important; }
   .text-info      { color: var(--info) !important; }
   (Note: .text-muted, .text-secondary, .text-body, .text-dark, .text-black, .text-reset were already theme-aware.)

2. Ensured alert classes have readable text in both themes (already present in darkmode.css):
   - Light mode: alert-success (#0f5132 on #d1e7dd), alert-danger (#842029 on #f8d7da), etc.
   - Dark mode: alert-success (#86efac on rgba(42,157,143,0.25)), alert-danger (#fca5a5 on rgba(231,111,81,0.25)), etc.

3. Ensured badge classes have readable text in both themes (already present in darkmode.css):
   - Light mode: badge-soft-* uses brand colors with soft backgrounds
   - Dark mode: badge-soft-* uses brighter text on slightly darker soft backgrounds
   - Standard badges (bg-*) use appropriate text colors (white or dark) based on background

4. Modified the showToast function in app.js to compute a contrasting text color (black or white) based on the toast background color's luminance, ensuring readability of toast messages on all brand-colored backgrounds.
